Core Capabilities
BEI Scoring
Entropy-weighted sum of 17 biomarker energy values. Module A (full panel) or Module B (KILL-4: D-dimer, SOFA, Lactate, PTX3). Returns score, zone, tipping marker, and per-marker tipping contributions.
AUC 0.812 — Davoudian et al. 2023 calibration
Immune Phenotyping
SRS1/SRS2-aligned classification using raw IL-10 concentration and CRP + SOFA. Detects HYPERINFLAMMATORY, IMMUNOPARALYSIS, and MIXED/TRANSITIONAL states with confidence and clinical implications.
IL-10 raw >50 pg/mL + SOFA ≥6 → IMMUNOPARALYSIS
ICD-10-CM Linkage
Three-level ICD code associations: per-marker, per-phenotype, and per-rule. Outcome-sensitive — R1 PASS returns N17.9 (AKI) while R1 TRIGGERED returns M62.50 (muscle wasting). Ready for clinical documentation.
Marker · Phenotype · Rule-outcome levels
Hard Clinical Rules
Five deterministic safety rules evaluated per patient: U:Cr catabolism (R1), IL-10 steroid contraindication (R2), DIC/ISTH gate (R3), CRRT per KDIGO (R4), protein target (R5). PASS / TRIGGERED / INDETERMINATE.
R2 TRIGGERED overrides any steroid recommendation
PDF Lab Parsing
Upload a blood report PDF. Extracts structured marker values with PyMuPDF, merges with JSON-supplied overrides, and runs full BEI analysis in a single round-trip.
POST /extract/pdf · POST /analyze/pdf
Longitudinal Tracking
PostgreSQL-backed patient histories. Re-submit labs to build a BEI trajectory. Analyses are immutable — full FDA audit trail with timestamp and hospital attribution.
GET /patients/{id}/analyses for full history

Authentication

Hospital API key, passed in every request

Each hospital tenant receives a unique API key at registration. Pass it as X-API-Key in the request header. Keys are rotatable without downtime via POST /hospitals/{id}/rotate-key.

The admin key — set via the ADMIN_API_KEY environment variable at startup — controls hospital registration, key rotation, and activation. It is never issued to tenants.

# Analyze patient markers curl -X POST https://your-api/analyze \ -H "X-API-Key: hosp_abc123..." \ -H "Content-Type: application/json" \ -d '{ "patient_id": "ICU-007", "markers": { "CRP": 210, "IL-10": 3.2, "SOFA": 11, "D-dimer": 3200, "Platelets": 95, "Lactate": 4.2 }, "include_xai": true }'
